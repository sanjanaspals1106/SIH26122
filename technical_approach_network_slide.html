⚡ Key Architectural Differentiators (Why SETUAI Wins Against Generic AI)

⚖️ WBS Granularity Bridge

Site engineers report "Pier Work Complete". SETUAI automatically uses Water-Fill Headroom Allocation to distribute progress across sibling tasks up to their 100% capacity without manual guesswork.

📈 Directional Conflict Filter

Stops erroneous progress regressions (e.g. 80% → 60%) unless tagged with an accepted REWORK code. Flags same-date contractor vs supervisor discrepancies >10% deterministically.

🎯 CPM-Aware Priority Scorer

Sorts the supervisor review queue using Score = 0.35(Critical) + 0.25(Float) + 0.25(Error) + 0.15(Age). Delays on critical path activities are pushed to the top instantly.

🔐 SHA-256 Tamper-Evident Chain

Every review, split, and edit is committed with Hash = SHA256(prev_hash + event_id + supervisor_id + timestamp + delta), creating a court-admissible audit trail.
