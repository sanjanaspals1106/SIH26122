# Contributing to SIH26122

## Branch Policy

`main` is the stable integration branch.

Do not develop directly on `main`.

Each feature must be developed on a separate branch.

### Branch naming

Use:

- `feature/schedules`
- `feature/intake`
- `feature/matching`
- `feature/checks`
- `feature/decisions`
- `feature/export`

For fixes:

- `fix/<short-description>`
